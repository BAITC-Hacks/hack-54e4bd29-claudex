# Диаграммы

Все диаграммы выполнены в Mermaid и хранятся как текст: они версионируются вместе с кодом, и изменение архитектуры видно в истории изменений как diff, а не как замена картинки.

| Файл | Уровень | О чём |
|---|---|---|
| [system-context.md](system-context.md) | Контекст | Система, пользователи, внешние источники |
| [containers.md](containers.md) | Контейнеры | Процессы и хранилища, их взаимодействие |
| [product-flow.md](product-flow.md) | Продукт | Путь от данных до контроля решения |
| [data-flow.md](data-flow.md) | Данные | Конвейер от выгрузки до витрины признаков |
| [signal-lifecycle.md](signal-lifecycle.md) | Домен | Формирование и жизненный цикл сигнала |
| [ml-pipeline.md](ml-pipeline.md) | ML | Конвейер обучения, приёмки и инференса |
| [deployment.md](deployment.md) | Развёртывание | Локальная и целевая топология |

Диаграммы уровня слоёв и границ модулей находятся в [ARCHITECTURE.md](../ARCHITECTURE.md), доменная ER-модель — в [DATABASE.md](../DATABASE.md).
