# MedSignal — кандидаты на целевую переменную

## Semantic correction — 2026-09-23

Исправлены только выводы о доступности целей, без повторного аудита исходных
выгрузок. Исходные fingerprint, количества строк и файлов, min/max дат и прочие
измерения сохранены. Прежнее `AVAILABLE` для двух целей было выводом по наличию
столбцов, а не подтверждением семантики:

- `queue_size(t+n)` — `NOT AVAILABLE / NOT FEASIBLE`,
  `NO_VERIFIED_SNAPSHOT_HISTORY`: даты регистрации за несколько месяцев внутри
  одного среза не образуют историю состояния очереди. Один срез пригоден для
  описательного подсчёта ожидающих на дату подтверждённого среза, не для прогноза.
- `refusal_rate` — `NOT AVAILABLE / NOT FEASIBLE`, `DENOMINATOR_NOT_ALIGNED`:
  совпадение дат и названий полей не доказывает общую популяцию числителя и
  знаменателя. Нужны подтверждённые организация, период, полнота и правила учёта.
  Число отказов можно описывать отдельно от неподтверждённой доли.

Даже подтверждение повторных сопоставимых срезов или выровненного знаменателя
даёт только `PARTIALLY AVAILABLE / REQUIRES_COVERAGE_REVIEW`; пригодность к
обучению требует отдельной проверки покрытия. Рост направлений не доказывает
перегрузку. Рекомендация исходного аудита остаётся отложенной.

Целевая переменная не выбиралась заранее. Ниже — проверка того, какие величины вычислимы с учётом найденных столбцов и подтверждённой семантики.

|---|---|---|---|
| queue_size(t+n) | NOT AVAILABLE | NOT FEASIBLE | NO_VERIFIED_SNAPSHOT_HISTORY: Не подтверждена история повторных сопоставимых срезов очереди |
| incoming_referrals(t+n) | AVAILABLE | WEAK | Все требуемые поля найдены в одной таблице |
| waiting_time_days | AVAILABLE | WEAK | Все требуемые поля найдены в одной таблице |
| refusal_rate | NOT AVAILABLE | NOT FEASIBLE | DENOMINATOR_NOT_ALIGNED: Не подтверждена общая популяция числителя и знаменателя |
