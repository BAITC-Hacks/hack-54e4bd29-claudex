## Описания поставщика

### Запущенность злокачественных новообразований по локализациям

Сводная статистика по запущенности злокачественных новообразований в разрезе локализаций (МКБ-10): общее число больных с впервые установленным диагнозом, число больных с III и IV стадиями, проценты запущенности. Используется временная таблица ##table7_3, заполняемая 23 INSERT-ами по фиксированным локализациям опухолей. Стадии III и IV определяются по фиксированному списку UUID.

Описание колонок:

"id (##table7_3) — порядковый номер локализации;

name (##table7_3) — наименование локализации (23 значения: ЗН губы, ЗН языка, ЗН десны и т.д.);

sickName (##table7_3) — шифр по МКБ Х пересмотра (например, 'C00', 'C01-02', 'C50');

COUNT(person_id) — число больных с впервые установленным диагнозом;

SUM(bolnih_s_3_stage) — всего больных с III стадией;

% запущенности III стадии — вычисляемое;

SUM(bolnih_s_4_stage) — всего больных с IV стадией;

% запущенности IV стадии — вычисляемое.

Стадии III/IV определяются по 4 UUID каждая из d.tumor_stage_id."

### Информация по онкобольным с впервые установленным диагнозом

Информация по онкологическим больным с впервые установленным диагнозом за отчётный период. Содержит большую часть полей датасета 1 + дополнительно две отметки: впервые установленный в жизни и впервые установленный в этом году (через oncomed_treatment_course).

Описание колонок:

"clinic_name, Возраст, number_card, take_in_date, take_of_date, Диагноз, diagnosis_date — как в датасете 1;

ru (val1) — причина снятия; ru (dcas) — причина смерти;

death_date, death_place, ru (val4) — соц.положение;

first_time_in_life_diagnosed (oncomed_treatment_course) — отметка о впервые в жизни (1→'Да', 0→'Нет');

first_time_in_year_diagnosed (oncomed_treatment_course) — отметка о впервые в году (1→'Да', 0→'Нет');

ru (val5, val6, val11, val9, val7) — взят на учёт, клин.группы, обстоятельства, инвалидность"

### Количество пролеченных случаев в разрезе МО

Агрегированный отчёт по количеству пролеченных случаев в разрезе медицинских организаций. Включает: всего выбыло больных, в т.ч. дети до 18 лет, пролечено по бюджету (по списку publCod), пролечено платно, выбыло в течение суток (койко-дней ≤ 1), всего умерло (по исходам), сумма проведённых койко-дней, сумма к оплате. Фильтрация: только проверенные случаи с датой выписки в отчётном периоде.

### Направления на плановую госпитализацию в стационары

Набор данных содержит сведения о направлениях на плановую госпитализацию в стационары за отчётный период. Включает код госпитализации, направляющую и принимающую медицинские организации, диагноз по МКБ-10, профиль койки, плановую и фактическую дату госпитализации, цель направления, источник финансирования, территориальный тип. Используется для мониторинга процесса планового направления пациентов на стационарное лечение.

### Ожидающие плановую госпитализацию в стационары

Набор данных содержит сведения о пациентах, ожидающих плановую госпитализацию в стационары. Включает разбор кода госпитализации (код области, МО, профиля и порядкового номера пациента), направительный диагноз по МКБ-10, код и наименование операции, даты регистрации и плановую дату. Используется для мониторинга очереди на плановую госпитализацию.

### Отказы в плановой госпитализации (приёмный покой)

Набор данных содержит сведения о случаях отказа в плановой госпитализации после обращения пациента в приёмный покой. Включает регион и медицинскую организацию обращения, территориальный тип проживания, статус застрахованности и категорию льготника, дату отказа, регион и МО прикрепления, диагноз по МКБ-10, предъявленную сумму к оплате и источник финансирования. Используется для мониторинга доступности стационарной помощи.

### Отказы от вакцинации и противопоказания

Набор данных содержит сведения об отказах от вакцинации и противопоказаниях. Включает идентификатор записи, причину отказа, противопоказание и наименование плана вакцинации. Фильтрация: записи со статусом 1 (отказ/противопоказание) за отчётный период.

Описание колонок:

id (vaccination) — уникальный идентификатор записи вакцинации;

name_ru (d_vaccination_deny_reason) — причина отказа от вакцинации (через JOIN с vaccination.reason_deny_id);

name_ru (d_contraindication) — противопоказание (через JOIN с vaccination.deny_contraindication_id);

name_ru (d_vaccination_plan) — наименование плана вакцинации (через JOIN с vaccination.vaccination_plan_code)

### Факты проведённых вакцинаций с возможностью представления в разрезе возрастов

Набор данных содержит факты проведённых вакцинаций с возможностью представления в разрезе возрастов. Включает идентификатор записи, дату проведения, возраст пациента на момент вакцинации, наименование плана вакцинации, код медицинской организации и регион. Используется для построения возрастных разрезов охвата вакцинацией. Фильтрация: только активные записи (deleted = false, status = 0 — проведена) за отчётный период.

Описание колонок:

id (vaccination) — уникальный идентификатор записи вакцинации;

injection_date (vaccination) — фактическая дата проведения вакцинации;

age (vaccination) — возраст пациента на момент вакцинации;

name_ru (d_vaccination_plan) — наименование плана вакцинации (через JOIN с vaccination.vaccination_plan_code);

med_org_code (vaccination) — код медицинской организации, проводившей вакцинацию;

name_ru (d_region) — наименование региона (через JOIN с vaccination.state_id)
