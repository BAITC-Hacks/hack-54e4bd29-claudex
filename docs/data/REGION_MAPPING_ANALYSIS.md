# MedSignal — анализ регионов

Регион — обязательный разрез анализа и административный справочник, поэтому значения в этом документе публикуются.

| Выгрузка | Столбец | Различных значений |
|---|---|---|
| Ожидающие плановую госпитализацию в стационары | `region_origin_code` | 20 |
| Отказы в плановой госпитализации (приёмный покой) | `region_in` | 20 |
| Отказы в плановой госпитализации (приёмный покой) | `attach_region` | 22 |
| Факты проведённых вакцинаций с возможностью представления в разрезе возрастов | `region` | 20 |

## Пригодность к единому справочнику

- `Ожидающие плановую госпитализацию в стационары.region_origin_code` пересекается с `Отказы в плановой госпитализации (приёмный покой).attach_region` на 0 из 20 значений
- `Отказы в плановой госпитализации (приёмный покой).region_in` пересекается с `Отказы в плановой госпитализации (приёмный покой).attach_region` на 20 из 20 значений
- `Факты проведённых вакцинаций с возможностью представления в разрезе возрастов.region` пересекается с `Отказы в плановой госпитализации (приёмный покой).attach_region` на 17 из 20 значений
