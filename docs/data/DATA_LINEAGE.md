# MedSignal — происхождение данных

## 1. Цепочка

```
файл в каталоге источника
   │ SHA-256 содержимого
   ▼
запись об импорте в PostgreSQL        data_imports.id, .file_hash
   │ import_id
   ▼
строка витрины в ClickHouse           import_id, source_file_hash
   │
   ▼
строка агрегата                       выводится из фактов представлением
```

Каждое звено восстановимо в обе стороны, и ни одно не содержит
идентификатора пациента.

## 2. Что хранит строка витрины

| Столбец | Что позволяет |
|---|---|
| `import_id` | найти запись об импорте: когда, кем, с каким результатом |
| `source_file_hash` | опознать исходный файл по содержимому, а не по имени |
| `source_system` | понять систему-источник |
| `ingested_at` | отличить момент загрузки от момента события |

## 3. Что хранит запись об импорте

| Поле | Смысл |
|---|---|
| `file_name`, `file_hash` | какой файл |
| `dataset_type`, `source` | какой набор и из какой системы |
| `status`, `started_at`, `completed_at` | что и когда произошло |
| `rows_read`, `rows_valid`, `rows_rejected`, `rows_loaded` | сходятся ли числа |
| `warnings_count` | сколько строк вызвало вопросы |
| `error_summary` | краткая причина отказа |
| `request_id` | связь с журналом приложения |

Счётчики хранятся вместе с записью, а не вычисляются запросом
к хранилищу: расхождение между источником и витриной нужно уметь
объяснить и после того, как раздел будет удалён политикой хранения.

## 4. Практические вопросы

**Откуда взялась эта строка витрины.**
`SELECT import_id, source_file_hash FROM fact_referral_events WHERE ...`,
затем запись об импорте по `import_id` в PostgreSQL.

**Загружался ли этот файл.**
Посчитать SHA-256 и найти его в `data_imports.file_hash`. Имя файла
значения не имеет.

**Почему в витрине меньше строк, чем в файле.**
Сравнить `rows_read`, `rows_rejected` и `rows_loaded` записи об импорте,
затем посмотреть замечания в `data_quality_results`, затем — сами
отклонённые строки в карантине.

**Что именно отклонено.**
`quarantine_batches` даёт адрес объекта и коды причин. Объект лежит
в зоне ограниченного доступа.

## 5. Запись в аудит

Регистрация импорта попадает в неизменяемый журнал действием
`DATA_IMPORT_REGISTERED` с указанием набора, имени файла и контрольной
суммы. Оператор командной строки не имеет проекции пользователя, поэтому
автор действия пуст; запись всё равно фиксирует, что и когда загружено.

## 6. Чего в цепочке нет

Идентификатора пациента. Ни одно звено не позволяет пройти от строки
витрины к человеку: связь обрывается на псевдониме, построенном HMAC
с секретом, которого в хранилище нет.
