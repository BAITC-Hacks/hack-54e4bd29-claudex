# MedSignal — конвейер загрузки данных

Документ описывает, как выгрузка превращается в аналитические записи
и почему путь устроен именно так.

## 1. Путь данных

```
файл в каталоге источника
   ↓ обнаружение          какие файлы относятся к набору
   ↓ отпечаток            SHA-256 содержимого
   ↓ идемпотентность      такой файл уже загружался?
   ↓ проверка схемы       состав столбцов совпадает с контрактом?
   ↓ разбор пакетами      файл целиком в память не читается
   ↓ нормализация         типы, пробелы, пустые строки
   ↓ проверки 4 уровней   файл, схема, справочники, бизнес-смысл
   ↓ псевдонимизация      идентификаторы заменяются HMAC-псевдонимами
   ↓ канонизация          набор столбцов витрины задан явно
   ↓ промежуточная таблица ClickHouse, раздел по идентификатору импорта
   ↓ сверка числа строк
   ↓ публикация           перенос в таблицу фактов
   ↓ сверка числа строк
   ↓ отчёт о качестве     PostgreSQL
   ↓ состояние импорта    COMPLETED
```

Отклонённые строки уходят в карантин, а не исчезают.

## 2. Где что живёт

| Часть | Где | Почему там |
|---|---|---|
| Разбор файлов, проверки, псевдонимизация, загрузка | `data_pipeline/` | Библиотека без знания о приложении. Её можно прогнать в тесте без базы (ADR-0005) |
| Жизненный цикл импорта, аудит, отчёт о качестве | `app/business/ingestion/` | Это правила системы, а не работа с файлами |
| Перевод между ними | `app/adapters/ingestion.py` | Единственное место, знающее обе стороны |
| Командная строка | `app/cli/data.py` | Композиционный корень, вне слоёв |
| Схемы витрин | `database/clickhouse/migrations/` | Версионированные файлы |

Образ исполнителя загрузки отдельный от образа API. Сервис, смотрящий
наружу, не обязан нести библиотеку потоковой обработки гигабайтных
файлов.

## 3. Каталог источника

Открывается только на чтение. В контейнере монтируется с флагом `ro`:
попытка изменить исходный файл отказывается ядром, а не вежливостью кода.

Путь задаётся снаружи и нигде не зашит:

```bash
make data-discover DATA_DIR=~/Downloads/data
```

## 4. Разрешающий список

Загрузить можно только четыре набора MedSignal Case 1:

| Ключ | Выгрузка | Источник |
|---|---|---|
| `REFERRALS` | Направления на плановую госпитализацию | ИС БГ |
| `WAITING` | Ожидающие плановую госпитализацию | ИС БГ |
| `REFUSALS` | Отказы в плановой госпитализации | ИС БГ |
| `TREATED` | Количество пролеченных случаев | ЭРСБ |

Выгрузки о вакцинации и онкологии в реестре отсутствуют, и загрузить их
невозможно. Это правило, а не внимательность оператора: рядом в каталоге
лежат 104 миллиона записей о вакцинации, не имеющих отношения к очереди
на госпитализацию.

## 5. Память

Файл читается пакетами. Каждый пакет проходит весь путь и освобождается,
поэтому расход памяти определяется размером пакета, а не размером файла.
Размер задаётся `DATA_BATCH_SIZE`, по умолчанию 50 000 строк.

Свойство проверяется тестом: на файле в двадцать раз большем пик памяти
растёт менее чем вчетверо.

## 6. Команды

```bash
make data-discover DATA_DIR=~/Downloads/data
make data-dry-run DATA_DIR=~/Downloads/data
make data-import-core DATA_DIR=~/Downloads/data
make data-import-referrals DATA_DIR=~/Downloads/data
make data-recover IMPORT_ID=<uuid>
make clickhouse-migrate
make clickhouse-status
```

Холостой прогон выполняет разбор, все проверки и псевдонимизацию, но
ничего не записывает: ни в ClickHouse, ни в PostgreSQL.

## 7. Чего конвейер не делает

- Не обучает модель и не считает прогноз. PHASE 3B не является этапом ML.
- Не сопоставляет организации по похожести наименований.
- Не исправляет данные. Найденное фиксируется, решение принимает владелец данных.
- Не принимает путь к файлу из запроса пользователя.
