# MedSignal — порядок загрузки данных

Пошаговая инструкция. Предполагается, что окружение поднято
(`make up`) и миграции PostgreSQL применены.

## 1. Подготовка

```bash
make pipeline-build
make clickhouse-migrate
make clickhouse-status
```

Каталог с выгрузками указывается переменной `DATA_DIR` и монтируется
только на чтение.

Секрет `DATA_PSEUDONYMIZATION_KEY` должен быть задан. Вне локальной среды
приложение не стартует со значением из примера или с ключом короче
32 символов.

## 2. Что видно в каталоге

```bash
make data-discover DATA_DIR=~/Downloads/data
```

Команда показывает только наборы из разрешающего списка. Выгрузки
о вакцинации и онкологии не показываются и загрузиться не могут.

## 3. Холостой прогон

```bash
make data-dry-run DATA_DIR=~/Downloads/data
```

Выполняет разбор, все четыре уровня проверок и псевдонимизацию. Ничего
не записывает: ни в ClickHouse, ни в PostgreSQL, ни в карантин.

Прогон обязателен перед первой реальной загрузкой новой поставки.
Смотреть в отчёте нужно на три вещи:

- сходятся ли прочитанные, принятые и отклонённые строки;
- есть ли замечания уровня ERROR;
- нет ли предупреждения о расхождении с отчётом Data Audit.

## 4. Загрузка

```bash
make data-import-core DATA_DIR=~/Downloads/data
```

Или по одному набору:

```bash
make data-import-referrals DATA_DIR=~/Downloads/data
make data-import-waiting   DATA_DIR=~/Downloads/data
make data-import-refusals  DATA_DIR=~/Downloads/data
make data-import-treated   DATA_DIR=~/Downloads/data
```

Повторный запуск безопасен: уже загруженные файлы пропускаются.

## 5. Проверка результата

```bash
curl -H "Authorization: Bearer $(make -s token)" \
     http://localhost/api/v1/data-imports
```

Сверить по каждому набору: прочитано = принято + отклонено, загружено =
принято. Расхождение означает дефект и требует разбирательства, а не
повторного запуска.

## 6. Если импорт упал

См. [IMPORT_RECOVERY.md](IMPORT_RECOVERY.md).

```bash
make data-recover IMPORT_ID=<uuid>
```

## 8. Что делать дальше не нужно

Конвейер не обучает модель и не считает прогноз. Целевая переменная
не выбрана: три месяца истории для этого недостаточно
([ADR-0014](../ADR/0014-forecast-target-deferred-after-audit.md)).
