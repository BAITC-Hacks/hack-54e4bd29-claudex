# Privacy в аналитическом слое

## Граница данных

ClickHouse уже получает только прошедшие privacy transformation факты. Исходные `hospitalization_code` и `patient_seq_no` отсутствуют в raw-виде. Analytics API не имеет event-level endpoints и не принимает произвольный SQL, имя поля или путь к файлу.

## Малые группы

`ANALYTICS_MIN_CELL_SIZE` по умолчанию равен 10. Для чувствительных разрезов (`resident`, `insured`, `benefit_category`, ICD group) группа меньше порога возвращается как:

```json
{"value": null, "suppressed": true}
```

Это защита конфиденциальности, а не статистическая оценка. UI показывает «Скрыто» и не пытается восстановить число.

## Scope

Cache key включает разрешённые canonical hospital IDs, флаги global/unmapped, фильтры и watermark импорта. Несопоставленные source-level организации закрыты от региональных и госпитальных ролей, потому что безопасно определить их регион пока невозможно.

В URL передаётся непрозрачный `source:<sha256>`, а не исходное название организации. Display name может присутствовать только в авторизованном агрегированном ответе как организационный, а не пациентский идентификатор.
