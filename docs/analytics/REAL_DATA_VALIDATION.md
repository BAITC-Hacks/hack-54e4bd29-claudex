## Возраст предоставленного среза очереди

На 765 182 записях: медиана 454,62 дня, P75 474,65 дня, P90 484,52 дня, максимум 497,08 дня. Эти числа описывают возраст записей в одном предоставленном срезе и не показывают историческую динамику очереди.

## Справочники и актуальность

- Представлено 3 239 безопасных source identity организаций и 40 представлений регионов.
- 5 029 aliases организаций и 42 aliases регионов имеют статус `UNMAPPED`; автоматическое объединение не выполнялось.
- Для всех четырёх наборов freshness имеет статус `UNKNOWN`, потому что периодичность поставки не определена.
- `source_load_date` доступен для waiting и treated. Для referrals и refusals он отсутствует в канонических фактах.

## Производительность

Измерение выполнено через nginx и реальный Keycloak token на локальном Docker Compose:

| Запрос | Время |
|---|---:|
| Overview, холодный cache | 442 мс |
| Overview, тёплый cache | 44 мс |
| Referrals DAY, без cache | 102 мс |
| Refusals DAY, без cache | 65 мс |

После двух одинаковых overview-запросов в изолированном Redis namespace создан один cache key. Ключ включает endpoint, фильтры, scope и watermark завершённых импортов.

## Ограничения интерпретации

Трёх месяцев истории недостаточно для годовой сезонности. Коечная мощность и подтверждённая целевая переменная перегрузки отсутствуют. Пролеченные случаи не имеют подтверждённого отчётного периода. Эти данные поддерживают описательную аналитику; они не подтверждают точность прогнозирования перегрузки.
