# ADR-0018: Immutable Scenario provenance and retry idempotency

## Статус

Принят.

## Контекст

Phase 7 сохраняет результат человеческого сценарного анализа. Повторный просмотр должен объяснять, какой baseline, период, watermark, Forecast и текст ограничений использовались. Обновление analytics или Forecast не должно менять исторический смысл сохранённого результата. При этом сетевой retry не должен создавать дубликаты.

## Варианты

1. Пересчитывать Scenario при каждом чтении. История меняется вместе с данными и перестаёт быть аудируемой.
2. Разрешить обновление одной Scenario. Новый выбор пользователя перезаписывает старое управленческое свидетельство.
3. Сохранять неизменяемый snapshot результата и provenance; отделить retry от нового намеренного Save.

## Решение

Выбран вариант 3.

`Scenario` хранит authoritative baseline, период, scope, предположение, результат, watermark, необязательную provenance Forecast, независимую temporal freshness, formula/limitations versions и snapshot ограничений. Репозиторий не предоставляет update/delete.

`POST /scenarios/preview` ничего не сохраняет. `POST /scenarios` повторно получает baseline и пересчитывает результат. `(created_by, client_request_id)` уникален: повтор того же запроса возвращает прежнюю Scenario без второго AuditEvent; другая полезная нагрузка с тем же ключом даёт конфликт. Новый осознанный Save использует новый UUID.

`Forecast.status` остаётся характеристикой валидности модели/результата. `baseline_freshness_status` отдельно хранит `CURRENT` или `STALE`. `STALE + VALID` — непротиворечивый исторический Forecast.

## Последствия

- Исторический расчёт полностью интерпретируем и не изменяется задним числом.
- PostgreSQL хранит небольшую audit-oriented сущность; ClickHouse и Celery не нужны.
- Изменение formula или disclaimer требует новой версии.
- Миграция 0006 отказывается фабриковать provenance для неизвестных legacy rows.

## Пересмотр

Решение пересматривается при появлении долгих сценарных моделей, но их результаты всё равно должны сохраняться неизменяемо с provenance.
