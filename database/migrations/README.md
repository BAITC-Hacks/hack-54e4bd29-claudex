# Миграции PostgreSQL

Миграции PostgreSQL выполняются Alembic и находятся в [`backend/alembic/`](../../backend/alembic/).

Расположение выбрано осознанно: файл окружения Alembic импортирует модели SQLAlchemy и настройки приложения, поэтому он должен лежать внутри пакета backend и попадать в его образ. Каталог `database/` остаётся за схемами ClickHouse и справочными данными.

## Команды

```bash
make migrate
```

```bash
make migration name="add_regions_table"
```

## Правила

| Правило | Причина |
|---|---|
| Одна миграция — одно смысловое изменение | Читаемая история и возможность отката |
| Откат реализован и проверен | Миграция без отката — односторонняя дверь |
| Изменение структуры и наполнение данными — разные миграции | Разный профиль риска и времени выполнения |
| Автогенерация просматривается перед применением | Alembic ошибается на типах и ограничениях |
| Миграции применяются отдельным шагом до выкатки | Исключает гонку между экземплярами приложения |

Состав таблиц и их назначение описаны в [DATABASE.md](../../docs/DATABASE.md).
